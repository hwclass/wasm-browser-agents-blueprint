🤝 Agent Handoff Demo

This demo showcases multi-agent coordination using a triage pattern. A routing agent (powered by WebLLM) analyzes your request and selects the appropriate specialized counter agent to execute the task.

How it works:

  • Triage Agent (JS + WebLLM) - Routes requests to specialized agents
  • Rust Counter (WASM) - High-performance word counting
  • Go Counter (WASM) - Portable word counting

Try different queries to influence routing: mention "performance" for Rust, "simplicity" for Go, or let the triage agent decide automatically.

💡 Mention "simple" or "demo" → Go | "fast" or "performance" → Rust | Short text → Go | Long text → Rust
