🛠️ Tool Calling Demo

This demo showcases manual tool calling with a browser-native agent. The agent (powered by WebLLM) outputs structured JSON to request tool execution, then synthesizes results into a final response.

Available Tools:

  • count_character_occurrences - Count how many times a character appears in text
  • visit_webpage - Fetch and read webpage content (mocked)
  • search_web - Search the web for information (mocked)

How it works: The agent is instructed to output JSON in the format {"kind":"tool_call","tool":"name","args":{...}} to call tools, or {"kind":"respond","message":"..."} for final responses. This approach is robust to WebLLM's current limitations with native function calling.

⚠️ Note: This uses manual JSON-based tool calling, not OpenAI-style function calling. The demo includes automatic retry logic and fallback handling for robustness.
